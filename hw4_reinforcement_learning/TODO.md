### Why is experience replay important in DQN?
    - Experience replay is important because it breaks temporal correlations, preserving i.i.d assumptions of regression

### What is the role of the target network in DQN? How does it improve stability?
    - the target network acts as a training stabilizer, ensuring that the model isnt chasing its own Q predicitons, which would be a moving target. It improves stability by making the target Q function static for a certain amount of steps. 

### What is Double DQN, and how does it reduce overestimation bias compared to standard DQN? (See: Deep Reinforcement Learning with Double Q-learning)
    - Double DQN is an approach used to reduce overestimation bias. It works by seperating the target evaluation network and online action selection network. This ensures that the argmax from the action selection doesnt consistently cause overestimated Q values, since the target network is less likely to agree with the online networks overestimation

### Why does PPO clip the probability ratio instead of directly constraining the KL divergence like TRPO? What goes wrong if you remove clipping entirely?
    - PPO clips the probability ratio instead of directly optimizng KL divergance to improve training stability when reusing the same sample multiple times. This allows for a single rollout to be used for multiple epochs of training. If you remove clipping entirely, taking multiple steps on the same data will cause overcorrections that can be potentially catastrophic to the learning process.

### PPO throws away all collected data after each update. Why can't you simply reuse old rollouts for more gradient steps?
    - PPO cannot reuse old rollouts because the stored advantages and log-probabilities were computed under a different policy. As the current policy diverges from the data-collecting policy, these estimates become inaccurate. The clipped objective limits the damage from stale data, but it also means the gradient signal diminishes .

### What does the GAE parameter (\lambda) control? What happens at the extremes (\lambda = 0) and (\lambda = 1)?
    - the GAE parameter controls the horizon of the advantage estimate. at lambda=0, the function only considers the next reward plus the critics esimate, whereas at lambda = 1, the function uses a full monte carlo estimate, takig into account all rewards from the rollout, and not considering the critics estimate. This controls the bias-variance tradeoff: lambda=0 gives low variance but high bias, while lambda=1 gives low bias but high variance
